# Screenshots

Placeholders. Capture these against your own tenant, or against the demo seed
(`python -m scripts.seed_demo`), and drop the files in here with these names so the
main README can reference them.

| File | What to capture |
| ---- | --------------- |
| `setup.png` | The Setup page after "Check the key", showing the derived tenant, region and fingerprint before saving |
| `dashboard-light.png` | Dashboard in light mode with the trend chart, action breakdown and top consumers |
| `dashboard-dark.png` | The same view in dark mode, to show both palettes |
| `limits.png` | Limits table with a mix of monitor only and enforcing rows, at least one near its limit |
| `limit-editor.png` | The new limit dialog with the enforcement warning visible |
| `notifications.png` | Notification Center with an active restriction and the Restore access button |
| `restore-confirm.png` | The restore confirmation dialog, which is the safety net worth showing |
| `audit-diff.png` | An audit entry's before and after diff, ideally for an enforcement action |
| `settings.png` | Settings page showing the scheduler and the unmatched usage table |

Two things to avoid when capturing: real usernames and email addresses, and a real
tenant name in the header. The demo seed uses example.com addresses for exactly
this reason.
